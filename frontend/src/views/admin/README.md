# 管理后台使用说明

## 功能模块

### 1. 仪表盘 (Dashboard)
- **用户数量统计**：显示系统总用户数、已测评用户数、高风险用户数、低风险用户数
- **风险等级分布图表**：使用 ECharts 饼图展示用户风险等级分布
- **活跃趋势可视化**：使用 ECharts 折线图展示用户活跃趋势

### 2. 诈骗案例管理 (FraudCaseManagement)
- **功能**：新增、编辑、删除诈骗案例
- **字段**：
  - 案例类型：短信、邮件、网站、电话、其他
  - 案例内容：诈骗/正常样例文本
  - 可疑特征提示：如钓鱼链接、恐吓等
  - 判定结果：诈骗/正常
  - 难度等级：简单、中等、困难

### 3. 识别训练题目管理 (TrainingQuestionManagement)
- **功能**：管理识别训练题目
- **字段**：
  - 关联案例：选择已创建的案例
  - 题目内容：训练题目描述
  - 选项：多个选项，可设置正确答案
  - 诈骗特征：可配置多个诈骗特征点

### 4. 风险测评问卷管理 (RiskAssessmentManagement)
- **功能**：管理风险测评问题
- **字段**：
  - 问题维度：信息保护意识、金融安全意识、心理风险倾向
  - 问题内容：测评问题描述
  - 选项：多个选项，每个选项有对应的风险分值
  - 权重：用于计算风险评分时的权重系数

### 5. 防骗知识库管理 (KnowledgeManagement)
- **功能**：管理防骗知识文章和视频
- **字段**：
  - 标题：知识标题
  - 分类：短信诈骗、邮件诈骗、网站诈骗等
  - 内容类型：文章或视频
  - 内容：支持 Markdown 格式
  - 视频URL：视频类型时填写
  - 封面图片：封面图片URL
  - 发布状态：已发布或草稿

### 6. 成就规则管理 (AchievementManagement)
- **功能**：配置成就规则和奖励
- **字段**：
  - 成就名称：成就显示名称
  - 成就描述：成就详细描述
  - 成就条件：训练次数、训练正确次数、完成测评等
  - 条件值：达到此值即可获得成就
  - 奖励经验值：获得成就时奖励的经验值
  - 图标URL：成就图标（可选）
  - 状态：启用或禁用

### 7. 用户数据管理 (UserManagement)
- **功能**：查看和管理用户数据
- **显示信息**：
  - 基本信息：用户名、昵称、邮箱、等级、经验值
  - 风险等级：低风险、中风险、高风险
  - 注册时间
- **用户报告**：点击"查看报告"可查看详细统计：
  - 训练统计：训练次数、正确次数、正确率、平均用时
  - 测评统计：完成测评次数、各维度得分、综合风险评分
  - 成就统计：获得成就数

### 8. 系统设置 (SystemSettings)
- **风险等级阈值配置**：
  - 低风险阈值：评分低于此值为低风险
  - 中风险阈值：评分在此值范围内为中风险
  - 高风险阈值：评分高于此值为高风险
- **经验值配置**：
  - 每次训练经验值
  - 每次正确经验值
  - 每次测评经验值

## 技术实现

### 布局结构
- **AdminLayout.vue**：管理后台主布局
  - 顶部 Header：系统名称 + 管理员信息 + 返回前台按钮
  - 左侧 Sidebar：功能模块菜单（使用 Element Plus Menu 组件）
  - 右侧 Content：内容管理区（使用 router-view 渲染子路由）

### 路由配置
- 使用嵌套路由结构
- 路径：`/admin` 为管理后台入口
- 子路由：
  - `/admin/dashboard` - 仪表盘
  - `/admin/cases` - 诈骗案例管理
  - `/admin/training` - 识别训练题目管理
  - `/admin/assessment` - 风险测评问卷管理
  - `/admin/knowledge` - 防骗知识库管理
  - `/admin/achievement` - 成就规则管理
  - `/admin/users` - 用户数据管理
  - `/admin/settings` - 系统设置

### API 接口
所有管理后台接口统一使用 `/admin` 前缀：
- `GET /admin/statistics/*` - 统计数据
- `GET/POST/PUT/DELETE /admin/cases` - 案例管理
- `GET/POST/PUT/DELETE /admin/training/questions` - 训练题目管理
- `GET/POST/PUT/DELETE /admin/assessment/questions` - 测评问题管理
- `GET/POST/PUT/DELETE /admin/knowledge` - 知识库管理
- `GET/POST/PUT/DELETE /admin/achievements` - 成就管理
- `GET /admin/users` - 用户列表
- `GET /admin/users/:id/report` - 用户报告
- `GET/PUT /admin/settings` - 系统设置

## 使用说明

1. **访问管理后台**：
   - 需要管理员权限（用户名为 "admin"）
   - 访问路径：`/admin` 或点击前台导航栏的"管理"按钮

2. **导航**：
   - 左侧菜单栏点击不同模块进行切换
   - 顶部可点击"返回前台"返回用户端

3. **数据操作**：
   - 各管理页面提供新增、编辑、删除功能
   - 使用 Element Plus 的 Dialog 组件进行表单编辑
   - 表单验证使用 Element Plus 的 Form Rules

4. **图表展示**：
   - 仪表盘使用 ECharts 进行数据可视化
   - 图表支持响应式调整

## 注意事项

1. 所有 API 调用都包含错误处理，当后端服务不可用时显示友好提示
2. 部分功能使用模拟数据，实际使用时需要后端 API 支持
3. 表单验证确保数据完整性
4. 删除操作需要二次确认，防止误操作
