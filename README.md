# Anti-Fraud Web

## 运行步骤

前端：

```bash
cd frontend
npm install
npm run dev
```

后端（可选，提供案例与知识库 API）：

```bash
cd backend
npm install
npm run dev
```

访问前端开发地址（默认 http://localhost:5173 ），后台 API 默认 http://localhost:3000/api。

## 功能路径（用于答辩演示）

- 首页：`/`
- 识别训练：`/train`（旧路径 `/challenge` 自动跳转）
- 风险测评：`/assessment`
- 风险报告：`/report`
- 防骗知识：`/knowledge`
- 个人中心：`/profile`
